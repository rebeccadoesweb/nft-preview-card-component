When I began this NFT preview card component challenge, I had a lot of fun with the card layout. I really enjoyed the challenge, and I'm glad I did it. I used tldraw to plan out the layout of the card. Then I recreated the design in Figma by creating color styles and using auto layout to position the elements.


Accessibility was the main focus in this project because the colors were not accessible to users with color blindness. FireFox Accessibility is a great resource for learning about accessibility with checking color contrast. I used `hsl(178 84% 32% / 0.5)` for the overlay color. Also I changed the color of ethereum icon to accent color without the opacity.
